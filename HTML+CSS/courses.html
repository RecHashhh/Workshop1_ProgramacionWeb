These are the three courses I am currently taking at Yachay Tech University during the second semester of 2026. For each one I list the instructor, the main topics of the syllabus, and the three things I personally expect to learn by the end of the term.

CA57 – Programación Web

Course code: CA57 · 2026SEM02UNICA-A00069

See it in the schedule Where the class is

The course is built around real software development practices. We work with technical documentation and API references, framework documentation and database manuals, we manage our code in GitHub repositories, and we deploy the result to cloud platforms.

Main topics

  • HTML & CSS
  • JavaScript
  • Frameworks
  • Docker and virtual hosts
  • Git and GitHub

Three topics I expect to learn

  1. HTML, CSS, JavaScript, jQuery and Bootstrap
  2. Postman for API testing
  3. Educational platforms (LMS: Moodle)

Instructor

Prof. Francisco Javier Hidrobo Torres

External resource

CA56-TA24 – Procesos Estocásticos

Course code: CA56-TA24 · 2026SEM02UNICA-A00263

See it in the schedule Where the class is

A course on signals and systems studied from a probabilistic point of view. It combines deterministic signal processing tools, such as the Fourier transform, with stochastic models used to describe random signals. It is the most mathematical subject of my semester.

Main topics

  • Fundamentals of signals and systems
  • Digital signal processing
  • Fourier series and harmonic analysis
  • Stochastic signal models
  • Stochastic systems and control

Three topics I expect to learn

  1. Correlation and spectral analysis of random signals
  2. Fourier transform and frequency-domain analysis
  3. Discrete-time LTI systems and the Laplace transform

Instructor

Prof. Diego Hernán Peluffo Ordoñez

External resource

Reference book I use for this course: Discrete-Time Signal Processing – Oppenheim & Schafer (opens in a new tab).

TM11 – Física II

Course code: TM11 · 2026SEM02UNICA-A00104

See it in the schedule Where the class is

The second physics course of the programme. It starts with oscillating systems, moves on to how those oscillations travel through matter as waves, and ends with the two great wave phenomena of classical physics: electromagnetism and optics. It includes a laboratory component where we measure these systems directly instead of only solving them on paper.

Main topics

  • Simple harmonic motion
  • Hooke's law
  • Mechanical waves
  • Electromagnetism
  • Optics

Three topics I expect to learn

  1. Reading a free-body diagram properly
  2. Force applied to a spring
  3. Propagation of mechanical waves

Instructors

  • Prof. Rosa Estefanía Almache Hernández
  • Prof. Julio César Chacón Torres

External resource

The textbook the course follows: Physics for Scientists and Engineers, Volume 2 – Serway & Jewett (Física para ciencias e ingeniería, opens in a new tab).
