Highlights

Full Stack Developer at Ripconciv

I build internal web tools for a national construction company, working on both the interface and the data layer. It is where I learned that a clear structure matters more than a clever one.

My main project there is the Audiovisual Hub, a web application that centralises the photo and video material of every construction site, together with the official brand assets and document templates of the company.

Desktop Application: Centinela

Centinela, built under the Triple-G Tech name, lets a business keep using the security cameras it already owns instead of replacing them. The program connects to the existing CCTV system and adds a detection model on top, so the value comes from the software and not from new hardware.

It counts people in real time, records unique visitors per day, and lets the user draw the exact area of the frame that should be watched. It stores everything locally in SQLite and runs on an ordinary computer, using either the CPU or the GPU. It is the project I am most proud of.
